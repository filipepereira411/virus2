Loop de Apps Gulosas (Windows)

Este ambiente simula o comportamento de scripts Batch (.bat) utilizados para testar o stress de memória no Windows ao abrir instâncias contínuas do navegador.

Código do Script Gerado:

@echo off
title Teste de Stress - Apps Gulosas
:loop
echo Abrindo instancia gulosa...
start chrome.exe --new-window "https://google.com"
timeout /t 2 >nul
goto loop
Aviso de Segurança: O script acima possui uma salvaguarda (pausa de 2 segundos) para evitar o travamento imediato do sistema. Use apenas para fins didáticos.
